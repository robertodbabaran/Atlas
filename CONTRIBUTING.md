# Contributing to Atlas

Thanks for your interest. Atlas is an early, personal project, and this document says how to take part today.

## What is welcome now

- **Issues:** bug reports, questions, and suggestions for the data model, the views or the documentation.
- **Citations:** a pointer to a primary source (a government database, a guideline, a peer-reviewed paper) that supports or corrects a knowledge-base note.

## What is paused

Outside code contributions (pull requests) are paused until a licence is chosen for the project. If you have a code change in mind, open an issue first and describe it.

## Ground rules

1. **Never include personal data.** Do not post real food logs, photos, health values, WHOOP data, tokens or credentials in an issue, comment or pull request.
2. **Use synthetic data** in any example, screenshot or sample file.
3. **Cite sources** for any health or nutrition claim, and say whether you opened the source.
4. **Be specific.** An issue should say what you expected, what happened, and the steps to repeat it.
5. **Be kind.** Disagree with ideas, not with people.

## Security problems

Do not report leaked secrets or security flaws in a public issue. Follow `SECURITY.md`.

## Not medical advice

This project does not give medical or dietary advice. See `DISCLAIMER.md`.
