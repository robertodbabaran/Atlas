# Roadmap

Atlas is early. The README lists what exists. This page lists where it is going. Dates are targets and move if the work does.

| Milestone | Target | What it delivers |
|---|---|---|
| v0.1 Ledger | 2026-11-22 | data model, invented sample data, export script, 7-day and 30-day views, the 30-day day-quality matrix, tests, continuous integration, first release |
| v0.2 Knowledge | 2026-12-20 | cited knowledge base, nutrient reference targets with sources, data-source credits, documentation page |
| v0.3 Link | 2027-01-31 | optional biometrics link: each user connects their own device account, sample response files, intake next to sleep and recovery |
| v0.4 Agent | 2027-03-31 | food-logging pattern: a photo or note becomes a ledger entry with a confidence label, with prompts, guardrails and a small evaluation set |
| v1.0 Atlas | 2027-06-30 | stable data model with schema versions, one-command install, complete docs, contribution policy and licence |

Progress is tracked in the repository's milestones and issues.

## Principles

- Plain files that can be read, diffed and backed up.
- Every number carries a confidence label.
- Real personal data never lives in this repository. Sample data is invented or heavily transformed.
- The public docs describe only what exists or is clearly marked as planned.
