# Source citation rules

Every knowledge entry cites what the author actually opened. These rules keep citations checkable.

## Required fields

| Field | Meaning |
|---|---|
| title | The title of the page, paper or document as shown |
| publisher | Who published it |
| date_published | As shown on the source. Write `unknown` if absent |
| date_read | The day the author opened it |
| locator | Link, or file name and page number |

## Rules

1. Cite the primary source when there is one. A news article about a study is not the study.
2. If only a secondary source was available, say so in the entry and label it accordingly.
3. One citation per claim. A list of five links under a paragraph does not show which one supports what.
4. Never cite a source you could not open. If it was paywalled, say that and cite only what was visible.
5. A changed page is a different source. Record the read date so a later reader knows which version you saw.
6. Do not invent page numbers. Leave the field empty.

## Checking

A reviewer should be able to open the locator and find the claim in under two minutes. If they cannot, the entry is returned to the author.
