# How to add a knowledge entry

A knowledge entry is a short, sourced note that a person wrote after reading something. It is not a ledger line and it is not a summary generated by a tool. The template is in `docs/KNOWLEDGE_ENTRY_TEMPLATE.md`; this page explains the steps.

## Steps

1. Open the source yourself. An entry written from a headline or from memory is not an entry.
2. Copy the template and give the file a short lowercase name with dashes.
3. Fill in the claim in one sentence, in your own words.
4. Add the citation: what you opened, who published it, the date you read it, and the link or file name. See `docs/SOURCE_CITATION_RULES.md`.
5. Set the confidence label. Use only the four labels in `docs/CONFIDENCE_LABELS.md`.
6. Say what the claim does not cover. One line is enough.
7. Run the sample checks before committing.

## What does not belong

- Figures that came from your own records. Those live in the ledger.
- Advice. An entry says what a source reports, not what anyone should do.
- Anything copied wholesale from the source. Quote at most one short sentence.

## When an entry is wrong

Add a new entry that points at the old one and says what changed. Do not edit the old file. The same rule as ledger corrections applies; see `docs/CORRECTIONS.md`.
