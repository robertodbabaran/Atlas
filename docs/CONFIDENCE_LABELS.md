# Confidence labels

Every figure in Atlas carries a label that says how it was obtained. The label travels with the number through every total and every view.

| Label | Meaning |
|---|---|
| label | read from a package label |
| weighed | measured on a scale |
| estimate | judged by eye or from a photo, recorded with a range |
| unconfirmed | entered without any check |

## Rules

- A total inherits the weakest label among its inputs. A day with one estimate is an estimate day.
- A missing value stays blank and is flagged. Atlas never fills a gap with a guess, a population average or a zero.
- Photo and visual estimates are recorded as an estimate with a range, and the range is shown.
- A figure copied from a reference database carries the database and record as its source.
- A correction is a new entry that points at the entry it replaces. The original is kept.

## Why

A confident-looking number built from weak inputs misleads. The label is the honest part of the number.
